HairStyle AI - Developed by Moin

1. Install Python 3.9 - 3.12 on your computer.
2. Easiest: double-click run.bat (Windows) or run "./run.sh" (Mac/Linux). Manual way: pip install -r requirements.txt
3. Manual start: python app.py
4. Connect your phone to the SAME Wi-Fi and open the URL printed in the terminal
   (example: http://192.168.1.5:5000).
5. Tap "Open Camera & Scan Face". Optional: in your phone browser menu choose
   "Add to Home Screen" so it opens like an app.

Real hairstyle photos: save any image as static/styles/<name>.jpg using one of these names
and it replaces the illustration automatically:
crop quiff side buzz tex layers bob pixie waves bun bangs curls

Privacy: photos are processed in memory and never saved.
Note: face shape is estimated from landmark ratios, so treat it as a guide, not a verdict.
